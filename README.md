# 词源星图 · Etymology Sky

> 把英语词根学习变成一场星空探索：词根是恒星，派生词是词星，三种题型是黯淡的行星，答对点亮，点开进入原创语段。

**作品链接**：【Qoder Sites 公网链接，发布后粘贴】

## 项目简介

词源星图是一个纯前端、免安装的交互式英语词根学习网页。它把 6 个高频词根做成 6 片星座，把 36 个派生词做成环绕词根的词星，把词义辨识、词形变换、语境填空三种题型做成每颗词星周围的 3 颗暗行星（共 108 颗）。学习者读语段、答对题，行星被点亮；3 颗行星全亮，词星亮起；6 颗词星全亮，整片星座升起。

目标用户是缺少优质英语学习资源、又不想再靠打卡硬背的大学生和自学者：打开一条链接就能用，不需要注册、不需要安装、不需要联网服务端，学习进度只保存在自己的浏览器里。

## 核心玩法：一条完整的学习闭环

```
词根（为什么是这个意思）
  → 词形（前缀 + 词根 + 后缀怎么拼出字面义）
    → 题型行星（在句子/语段里判断一次）
      → 语段（把这个词放回真实语境读一遍）
        → 点亮反馈（行星 → 词星 → 星座）
```

- **词根**：不是一张要背的清单，而是一片有来源故事的星座。点击词根恒星，先看拉丁语/希腊语出处与含义的演变。
- **词形**：星图连线直接标出前缀方向（in- 向内、pro- 向前、trans- 穿过……），词星信息卡展示音标、词性、拆解与「字面义 → 实际义」。
- **题型行星**：每题背后是一段 45–90 词的原创英文语段，三种题型依次追问「词义对不对、词形对不对、语境里通不通」；答错即时解析、可重试。
- **点亮反馈**：答对一题点亮一颗行星，三题全亮词星变亮，整片星座点亮；顶部进度环实时显示 108 颗行星的完成度。

## 技术栈与架构

- **前端**：原生 HTML + CSS + JavaScript，无框架、无构建工具、无 npm 依赖。
- **渲染**：Canvas 2D 绘制星空背景、星点、连线、标签与点亮动效；DOM 负责信息卡、抽屉面板、导航等 UI。
- **数据**：经典脚本挂载全局 `window.ETYMOLOGY_ROOTS`（`js/data.part1.js` + `js/data.part2.js`），由 `js/data.js` 合并为带站点元信息的 `window.ETYMOLOGY_DATA`，与渲染层解耦。
- **模块组织**：IIFE 挂载 `window.ES` 命名空间，避免全局污染；脚本按依赖顺序引入。
- **持久化**：`localStorage` 保存已点亮行星与音效偏好的本地状态；无账号、无后端、数据不出本机。
- **响应式**：桌面 / 平板 / 手机三档布局，`devicePixelRatio` 适配高清屏，`requestAnimationFrame` 驱动动画。

## 本地运行

项目没有构建步骤，两种方式任选：

**方式一：双击打开**

双击 `打开星图.bat`（或 `index.html`）即可，进度会保存在该浏览器本地。`打开星图.bat` 只是替你调用默认浏览器打开 `index.html`；若浏览器对 `file://` 下的脚本或本地存储有限制，改用方式二。

**方式二：本地静态服务器（推荐）**

```powershell
cd etymology-sky
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000>。Windows 上如果 `python` 无响应，试试 `py -m http.server 8000`。

> 数据校验需要 Node.js（仅开发时用，运行网页本身不需要）：

```powershell
cd etymology-sky
node tools/validate-data.mjs
```

通过时会打印 `6 个词根 / 36 个单词 / 108 道题` 与 `校验通过 ✦`。

## 数据规范入口

所有内容以 [`DATA_SCHEMA.md`](DATA_SCHEMA.md) 为唯一契约：

- 6 个词根固定为 spect（看）/ port（携带）/ tract（拉）/ dict（说）/ graph（写）/ bio（生命），各有固定配色；
- 每个词根 6 个派生词，每个词 1 段原创英文语段（45–90 词，含一处 `[[目标词]]` 标记）+ 中文翻译 + 3 道题（`meaning` → `form` → `cloze`，各 4 选项、答案下标 0–3、解析）；
- 合计 **6 词根 / 36 单词 / 108 题 / 36 段语段**；
- 修改数据后必须运行 `node tools/validate-data.mjs`，要求 **0 error**。

新增词根时，只需按 schema 补数据、重跑校验，渲染层会自动按数量计算星座布局。

## 设计与技术取舍

- **为什么没有后端**：学习产品最容易死在「登录—同步—崩溃」上。零后端让打开成本为零，也让隐私风险为零；代价是不跨设备同步，进度只在本机。
- **为什么用 Canvas 而不是 DOM**：星图的核心是空间关系与连续动画（镜头推近、连线、行星点亮）。Canvas 一次绘制更可控，也避免为上百个星点建 DOM 节点。
- **为什么不做打卡 / 排行榜**：它们服务留存，不服务理解。我们只做「构词讲清楚、语境给真实、反馈要即时、错题能重看」。
- **已知限制**：目前固定 6 个词根、36 个词；进度不跨设备；触屏只支持拖拽漫游（未做双指缩放）；开启 `prefers-reduced-motion` 时页面会关闭大部分装饰动画。
